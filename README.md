# Учебное FastAPI-приложение

Небольшое учебное веб-приложение с регистрацией, входом и профилем пользователя. Используются FastAPI, SQLModel, SQLite и Jinja2.

## Запуск

Нужен Python 3.13 или новее.

```powershell
uv sync
Copy-Item .env.example .env
uv run fastapi dev
```

После запуска приложение доступно по адресу <http://127.0.0.1:8000>.

Для запуска через отладчик VS Code можно использовать конфигурацию `Python Debugger: FastAPI` из `.vscode/launch.json`.

## Структура

- `main.py` — точка входа приложения.
- `app/` — модели, настройки, безопасность и роутеры.
- `templates/` — HTML-шаблоны.
- `static/` — CSS, JavaScript и статические изображения.
- `media/` — локальные загруженные аватары.

Локальные настройки, база SQLite, виртуальное окружение и загруженные аватары намеренно не добавляются в Git. Для них используется `.gitignore`.
