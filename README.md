# База пользователей

Учебное веб-приложение на FastAPI для регистрации пользователей, ведения профилей и поиска по учебным данным.

## Возможности

- регистрация и вход с cookie-сессией;
- каталог пользователей с фильтрами по ФИО, логину, курсу, факультету и типу обучения;
- редактирование профиля и загрузка аватара;
- разграничение доступа для обычных пользователей и администраторов;
- административный каталог скрытых профилей;
- рейтинг заполненности профилей;
- просмотр и выгрузка журнала действий в JSON.

## Технологии

- Python 3.13+;
- FastAPI и Jinja2;
- SQLModel/SQLAlchemy и SQLite;
- Pydantic Settings;
- pwdlib с Argon2 для хеширования паролей;
- Pillow для обработки аватаров;
- JavaScript, Bootstrap и CSS для интерфейса.


## Запуск

Требуется установленный [uv](https://docs.astral.sh/uv/).

Команды ниже выполняются в Bash, Git Bash или Linux/macOS:

```bash
git clone <url-репозитория>
cd web

uv sync
cp .env.example .env
uv run fastapi dev
```

После запуска откройте <http://127.0.0.1:8000>.

Для запуска с демонстрационными данными выполните до запуска сервера:

```bash
uv run python seed.py
```

Команда заполнит SQLite-базу примерами пользователей и администратора. Запускать её повторно в уже заполненной базе не следует, так как имена пользователей должны быть уникальными.

## Структура

- [`main.py`](main.py) — точка входа приложения;
- [`app/`](app) — модели, настройки, безопасность, работа с файлами и роутеры;
- [`templates/`](templates) — HTML-шаблоны;
- [`static/`](static) — JavaScript, CSS и статические изображения;
- `media/` — загруженные аватары;
- `database.db` — локальная SQLite-база.
